
#### Dois tipos de expectativa
- **O serviço desejado** é uma combinação do que o cliente acredita que "é possível" e "deveria ocorrer" -> **Limite superior**
- **O serviço adequado** representa "a expectativa mínima tolerável", o nível mais baixo de desempenho aceitável para o cliente (Zeithaml, Jo Bitner, et al., 2014). -> **Limite inferior**

-> Se o desempenho percebido cai dentro destes limites, o serviço é aceitável. 
-> Se o serviço estiver abaixo do adequado o cliente o avalia como insatisfatório.
-> Se o serviço estiver acima, o cliente tem uma grande satisfação ou encantamento.

- A zona de tolerãncia pode variar com o tempo
- Pode variar de indivíduo para indivíduo 
- Pode ser larga ou estreita
- Pode variar com o tipo de produto/serviço
