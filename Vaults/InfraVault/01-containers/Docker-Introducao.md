##### A promessa do Docker

As funções do Docker se expandem em segmentos diferentes da indústria e incluem tecnologias como [[KVM]], [[Xen]], [[OpenStack]], [[Mesos]], [[Capistrano]], [[Fabric]], [[Ansible]], [[Chef]], [[Puppet]], [[SaltStack]] (segmentos isolados da pipeline de [[DevOps]]) e etc..

O [[Docker]] possui uma diversificada gama de ferramentas para lidar com os desafios de um [[workflow]]. Combinando features de ferramentas de [[Deployments]] como [[Capistrano]] e [[Fabric]] e de ferramentas de [[Virtualizacao]], fornecendo [[hook]]s que facilitam a automação e orquestração de fácil implementação. 

O [[Docker]] surge como solução para enfrentar e agilizar problemas de comunicação entre diferentes equipes de uma organização, além de promover uma arquitetura saudável de software que favorece robustez, uam vez que é centrada em [[Container Docker |containers]] atômicos e/ou descartáveis. 


##### Benefícios do workflow do docker

- Empacotamento de software.
- Software da aplicação e arquivos de sistema operacional (dependências) em uma [[Docker-Images| imagem]] com formato padronizado.
- Uso de artefatos para teste e entrega do exato mesmo artefato para todos os sistemas em todos os ambientes.
- Abstração entre software e hardware sem sacrifício de recursos.
