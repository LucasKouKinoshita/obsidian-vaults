# Bibliografia - Infraestrutura de Software

Esta bibliografia contém recursos essenciais para estudar infraestrutura de software, organizados por categoria e nível de dificuldade.

## Livros Fundamentais

### Sistemas Operacionais
- **"Operating System Concepts"** - Abraham Silberschatz, Peter Baer Galvin, Greg Gagne
  - *Nível*: Intermediário
  - *Foco*: Conceitos fundamentais de SO
  - *Relevância*: Base para entender containers e virtualização

- **"Linux System Administration"** - Tom Adelstein, Bill Lubanovic
  - *Nível*: Iniciante
  - *Foco*: Administração de sistemas Linux
  - *Relevância*: Essencial para infraestrutura moderna

- **"UNIX and Linux System Administration Handbook"** - Evi Nemeth, Garth Snyder, Trent R. Hein
  - *Nível*: Avançado
  - *Foco*: Administração avançada de sistemas
  - *Relevância*: Referência completa para administradores

### Redes de Computadores
- **"Computer Networks"** - Andrew S. Tanenbaum, David J. Wetherall
  - *Nível*: Intermediário
  - *Foco*: Fundamentos de redes
  - *Relevância*: Base para networking em infraestrutura

- **"TCP/IP Illustrated"** - W. Richard Stevens
  - *Nível*: Avançado
  - *Foco*: Protocolos TCP/IP em detalhes
  - *Relevância*: Compreensão profunda de networking

- **"Network Security Essentials"** - William Stallings
  - *Nível*: Intermediário
  - *Foco*: Segurança de redes
  - *Relevância*: Segurança em infraestrutura

## Ordem de Estudo Recomendada

### Iniciante (0-6 meses)
1. **Sistemas Operacionais** - Linux System Administration
2. **Redes** - Computer Networks
3. **Docker** - Docker: Up & Running
4. **Cloud** - AWS Well-Architected Framework

### Intermediário (6-18 meses)
1. **Kubernetes** - Kubernetes: Up and Running
2. **Monitoramento** - Site Reliability Engineering
3. **Segurança** - Container Security
4. **Automação** - Terraform: Up & Running

### Avançado (18+ meses)
1. **SRE** - The SRE Handbook
2. **Observabilidade** - Observability Engineering
3. **Arquitetura** - Building Microservices
4. **Segurança Avançada** - Security Engineering
