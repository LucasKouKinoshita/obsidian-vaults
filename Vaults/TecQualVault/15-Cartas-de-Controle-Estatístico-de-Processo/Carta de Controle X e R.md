#### gráfico R
Você utiliza este gráfico somente quando o tamanho da amostra é igual ou menor do que 10, caso contrário, preferir gráfico para o desvio-padrão
##### Fórmulas
LSC = R_barra D_4
LIC = R_barra D_3
LC = R_barra
R -> amplitude
R_barra -> média de amplitudes

#### gráfico x_barra
Depois de verificar que a amplitude está sob controle utilizando o Gráfico R, examinar e verificar o comportamento da média aritmética do processo pelo gráfico 𝑥
LSC = x_barra_barra + A2 R_barra
LIC = x_barra_barra - A2 R_barra
LS = x_barra_barra
x_barra -> média das medidas
x_barra_barra -> média das médias
