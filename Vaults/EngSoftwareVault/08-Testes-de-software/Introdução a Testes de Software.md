- Sistemas de software estejam sujeitos aos mais variados tipos de erros e inconsistências.
-  teste é uma das práticas de programação mais valorizadas hoje em dia, em qualquer tipo de software.
	- É também uma das práticas que sofreram mais transformações nos anos recentes.
	
"Se um código não é acompanhado de testes, ele pode ser considerado de baixa qualidade ou até mesmo um código legado" _Michael Feathers_


#### Desenvolvimento em cascata
- Testes ocorriam em uma fase separada, após as fases de levantamento de requisitos, análise, projeto e codificação
- Equipe separada e responsável
- [[Testes manuais]]

#### Métodos ágeis
- [[Testes automatizados]] em grande maioria
	- Devs além de implementar classes também passam a implementar código para testar classes
	- Programas **auto-testáveis**
- Testes implementados ao decorrer da codificação ou até mesmo antes ([[Desenvolvimento Dirigido por Testes (TDD)]])
- Não são mais uma ferramenta exclusivamente de detecção de [[bug]]s. 
	- Garantem que uma classe continuará funcionando como esperado após alterações em outras partes do sistema
	- Usados como documentação
